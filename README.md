'Project Provines' is an MMORPG with a third-person perspective.
An interesting game developed from a third-person perspective in which the main goal is to become stronger, defeat the main enemies of the hero, and achieve the maximum level of respect in different worlds. The main character's name is Pram, he starts his journey in the wild forests, randomly finding these zones, he is waiting for long adventures with other players, improve your equipment, kill monsters, achieve maximum experience and level and a decent level of equipment. Beautiful biome worlds, good graphics, high-quality battles - all this you will find in the game ‘Project Provines’.
